# Contributing to SONIC_unitree_h2

This repository maintains Unitree H2 simulation, hardware deployment, and VR teleoperation.

Report reproducible deployment issues through [GitHub Issues](https://github.com/QinnyuLan/SONIC_unitree_h2/issues). Include the operating system, GPU, Python/native library versions, launch command, and relevant logs.

For changes, run the offline checks in [Reproducibility](docs/REPRODUCIBILITY.md), update the affected English and Chinese deployment instructions, and open a pull request against `main`. Describe which simulation or hardware checks were performed. Keep device-specific settings and runtime recordings out of commits.

Contributions are covered by the source-code license in [LICENSE](LICENSE).
