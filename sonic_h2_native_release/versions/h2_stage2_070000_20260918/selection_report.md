# 第二阶段模型选择，2026-09-18

推荐原始两阶段实验的 **stage2 step 70,000**（加 stage1 2,000，累计 72,000 轮），用于下一步 H2 真机试部署。训练窗口筛选和固定动作仿真比较支持这一选择；没有连接真机，也没有验证用户外部 H2 runtime。

## 选择依据

先检查旧实验所有保存 checkpoint 的前 500/1,000 轮日志及迁移实验 6k 模型，筛出旧 70k 与 73,150；用旧30k作参考。6k 尚未充分收敛。
固定动作测试中，70k 与73150根部和末端跟踪接近；70k关节误差较低，动作变化较小。H2根部的微小差异不足以认定显著优势，选择依据主要是整体跟踪与动作平顺性的折中。
按采样时刻加权的 normalized action 增量平方 L2，70k比73150低：H2 3.60%，SMPL 3.70%。这只是仿真动作变化指标，不等于实机电机冲击或功耗。

## 固定动作测试

- 同一随机种子18，从24,715条配对动作中抽取256条唯一动作，每条动作第一帧起跑。
- 每环境仅计第一次回合，最多20秒；256个并行环境。保留训练终止条件，关闭事件、观测噪声、reset噪声、动作增强、ADP，使用确定性action_mean。
- 分别测试纯H2及纯SMPL；G1 teacher从未被选择。误差在物理步后、自动reset前采集，包含失败末帧。下表先对每条动作取均值，再对256条动作等权平均。
- 每次policy参数和buffers前后SHA一致，optimizer_steps=0。全部motion清单hash一致。

## 统计解释

256条动作配对bootstrap（20,000次）比较73150−70k：H2根部差0.0079cm，95%区间[-0.4371,0.4662]cm；关节差0.000748rad，区间[0.000336,0.001171]rad；动作等权增量平方差0.02536，区间[0.01378,0.03725]。根部和末端差异不明确，关节与平顺性支持70k。该区间只描述此动作样本，不覆盖随机化、种子或真机差异。
